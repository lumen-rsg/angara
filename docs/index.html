Philosophy
Explicit is better
than implicit.

Every design decision in Angara follows one principle: the programmer should never be surprised by what the compiler does. Types are annotated, not inferred behind your back. Memory is verified, not silently collected. Contracts are declared, not assumed.

⚙

No Hidden Allocations

Every heap allocation is visible. You new it explicitly, you drop it explicitly — and the Chaperone proves you did it right. No autoboxing, no implicit heap promotion, no compiler-generated copies you didn't ask for.

★

No Implicit Conversions

i64 does not become f64 silently. string does not become any without your consent. Every type conversion is deliberate, every cast is explicit, every boundary is enforced.

⚡

No Runtime Collector

There is no garbage collector. No tracing, no refcounting, no safepoints, no pauses. Memory safety is a compile-time proof, which means the language is sound on freestanding targets — kernels, drivers, embedded.

⚖

Contracts First

Define what a type must provide before you define how it provides it. The contract keyword enforces field presence and method signatures at compile time. Interface by design, not by convention.

🔗

Zero-Cost C FFI

Call any C library with a foreign declaration. Map C structs directly. No wrapper generation, no binding layers, no runtime overhead. The C ABI is a first-class citizen.

⚑

Bare-Metal Ready

Compile to freestanding ARM64 with --freestanding --target aarch64-unknown-none-elf. Write kernels, firmware, and embedded code with the same language, the same type system, the same guarantees.

Memory Model
The Chaperone:
not a collector — a verifier.

Angara v5 removed its garbage collector entirely. In its place, the Chaperone is a compile-time data-flow analysis pass that verifies memory safety rather than managing memory at runtime. You allocate explicitly, you drop explicitly — the Chaperone proves every allocation is released and catches use-after-free, double-free, and leaks before the binary ever runs.

No Collector

No tracing, no refcount, no safepoints. Memory safety is proven at compile time, so there is nothing to pause or synchronize at runtime.

Freestanding-Sound

Because safety is a compile-time property, the same guarantees hold on bare metal — kernels, drivers, and embedded targets with no runtime at all.

Not Rust

No lifetimes in the type system. No borrow checker that rejects code. The Chaperone is a verifier — it reports exactly where it can't prove safety.

Move Semantics

A tracked allocation has exactly one owner. Assigning it moves ownership; the old name is invalidated — the core of the double-free guarantee.

Ownership Keywords
Four ways to hold memory.
data pure value
Copy-on-assign (memcpy). Stack/inline. The Chaperone ignores it — no tracking, no drop. The zero-cost case.
value semantics
data Point { let x as i64; let y as i64; }
let p1 = Point(10, 20);
let p2 = p1;            // deep copy — independent
p2.x = 99;
// p1.x is still 10
owned tracked
Heap-allocated via the Allocator. The Chaperone tracks its whole lifetime — it must be explicitly dropped or ownership-transferred.
tracked allocation
owned Buffer {
  let value as i64;
  func fin(this) { /* finalizer */ }
}
let buf = Buffer();
// ... use buf ...
drop buf;              // required — else E501 leak
class tracked
Owned by default — every instance is tracked and heap-allocated, same as owned, plus methods and inheritance.
move semantics
class Conn {
  let port as i64;
  func init(this, p as i64) { this.port = p; }
}
let a = Conn(80);
let b = a;   // MOVE: b owns it; a is invalid
drop b;      // only the owner drops
ref<T> borrow
A non-owning reference. Borrows a tracked object without owning it — the Chaperone checks the borrow doesn't outlive its referent.
borrow-checked
let b = Buffer();
let r as ref<Buffer> = b;  // borrow
drop b;
// r.get() here → E509 dangling borrow
Diagnostics
Every bug class, named and caught.

The Chaperone runs after the type checker and halts compilation on any error below. Each diagnostic is a molecular metaphor — an unfolded molecule is a leak, a dead reference is a use-after-free.

CodeMetaphorWhat it catches
E501🧬 Unfolded moleculeMemory leak — allocation has no drop on a control-flow path
E502💀 Dead referenceUse-after-free — variable used after drop
E503⚠️ Double denaturationDouble-free — dropped twice, or after ownership moved
E504🔗 Tangled moleculeReference cycle — use ref<T> for the back-edge
E505🧬 Escaped moleculeTracked value escapes into an untracked container or closure
E506🔄 Incomplete foldLoop-body drop — double-free on iteration 2+
E507📤 Moved moleculeUse-after-move — a moved-from variable is read
E509🔗 Dangling borrowA ref<T> is read after its referent was released
W510(warning)Variable handled differently on if/else branches

Type System
Contract-First
Awareness

The contract keyword defines what a type must provide — both fields and methods — before you write any implementation. Classes declare their contracts with signs, and the compiler verifies every obligation.

Define contracts
export contract Identifiable {
  public:
    let id as i64;
}

export contract Loggable {
  public:
    func to_log_string(this) -> string;
}

export contract Serializable {
  public:
    func to_json(this) -> string;
    func from_json(this, data as string) -> nil;
}
Sign contracts with a class
class User signs Identifiable, Loggable {
  public:
    let id as i64 = 0;
    let name as string;

  public:
    func init(this, id_val as i64,
                   name_val as string) -> nil {
      this.id = id_val;
      this.name = name_val;
    }

    func to_log_string(this) -> string {
      return "[User#" + string(this.id)
             + "] " + this.name;
    }
}

echo_server.an — WebSocket echo server in ~20 lines
attach Server, WebSocket, createServer from websocket;
attach io;

let clients as list<WebSocket> = [];
let mutex as Mutex = Mutex();

func on_connect(server as Server, client as WebSocket) -> nil {
  mutex.lock();
  clients.push(client);
  mutex.unlock();
  client.send("Welcome!");
}

func on_message(server as Server, client as WebSocket,
                  message as string) -> nil {
  mutex.lock();
  for (c in clients) { c.send("echo: " + message); }
  mutex.unlock();
}

export func main() -> i64 {
  let server = createServer(8080, {
    "on_connect": on_connect,
    "on_message": on_message
  });
  while (true) { server.service(); }
}
