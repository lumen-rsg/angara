Philosophy
Explicit is better
than implicit.

Every design decision in Angara follows one principle: the programmer should never be surprised by what the compiler does. Types are annotated, not inferred behind your back. Memory is tracked, not silently collected. Contracts are declared, not assumed.

⚙

No Hidden Allocations

Every heap allocation is visible. String concatenation creates a new object — and you know it. No autoboxing, no implicit heap promotion, no compiler-generated copies you didn't ask for.

★

No Implicit Conversions

i64 does not become f64 silently. string does not become any without your consent. Every type conversion is deliberate, every cast is explicit, every boundary is enforced.

⚖

Contracts First

Define what a type must provide before you define how it provides it. The contract keyword enforces field presence and method signatures at compile time. Interface by design, not by convention.

☯

Biological GC

The garbage collector is inspired by protein folding — molecular chaperones that guide heap compaction incrementally, using simulated annealing to optimize object locality without stopping the world.

⚡

Zero-Cost C FFI

Call any C library with a foreign declaration. Map C structs directly. No wrapper generation, no binding layers, no runtime overhead. The C ABI is a first-class citizen.

⚑

Bare-Metal Ready

Compile to freestanding ARM64 with --freestanding --target aarch64-unknown-none-elf. Write kernels, firmware, and embedded code with the same language, the same type system, the same guarantees.

Memory Management
ChaperoneGC:
Protein Folding
Meets the Heap

In molecular biology, chaperone molecules guide proteins to fold into their lowest-energy configurations — dense, compact, functional 3D structures. ChaperoneGC applies the same principle to heap memory.

The Hydrophobic Effect

Proteins fold because hydrophobic residues collapse inward, forming a dense core, while hydrophilic residues remain exposed. ChaperoneGC treats frequently-referenced objects as hydrophobic — they cluster together for cache locality — while cold or dying objects drift to arena edges, ready for collection.

Simulated Annealing

The background chaperone thread proposes small object relocations, accepting energy-improving moves always and energy-increasing moves probabilistically (exp(-ΔE/T)). Temperature cools over time, then periodically reheats to avoid premature convergence — exactly like thermal fluctuations during protein folding.

Architecture
Three Mechanisms,
One Metaphor
01
Bump-Arena Allocation

Biological Parallel:
Co-Translational Folding

Just as proteins begin folding while still being synthesized by the ribosome, Angara objects are bump-allocated into thread-local arenas. Allocation is a single pointer increment — contiguous objects are already partially "folded" from birth. Each arena is 1MB, up to 256 arenas (256MB total).

02
Energy Landscape

Biological Parallel:
Free Energy Minimization

Each arena has a computed "free energy" score based on fragmentation, pointer distance, and cache behavior. Hot objects with many incoming references cluster like hydrophobic residues in a protein core. The chaperone thread continuously evaluates this energy landscape, seeking the global minimum.

03
Simulated Annealing

Biological Parallel:
Chaperone-Mediated Refolding

Molecular chaperones (Hsp60/GroEL, Hsp70) resolve misfolded proteins incrementally, without stopping the cell. ChaperoneGC's background thread relocates objects one at a time using forwarding pointers — mutators never pause. Temperature cools at T × 0.9999, reheats every 10,000 steps.

Type System
Contract-First
Awareness

The contract keyword defines what a type must provide — both fields and methods — before you write any implementation. Classes declare their contracts with signs, and the compiler verifies every obligation.

Define contracts 
export contract Identifiable {
  public:
    let id as i64;
}

export contract Loggable {
  public:
    func to_log_string(this) -> string;
}

export contract Serializable {
  public:
    func to_json(this) -> string;
    func from_json(this, data as string) -> nil;
}
Sign contracts with a class 
class User signs Identifiable, Loggable {
  public:
    let id as i64 = 0;
    let name as string;

  public:
    func init(this, id_val as i64,
                   name_val as string) -> nil {
      this.id = id_val;
      this.name = name_val;
    }

    func to_log_string(this) -> string {
      return "[User#" + string(this.id)
             + "] " + this.name;
    }
}
Contracts vs. Traits

Angara provides two complementary abstraction mechanisms. Contracts can require fields; traits cannot. Both require method implementations.

Distinctive Keywords

Every keyword in Angara serves a purpose. No compound constructs, no ambiguity.

orif

A first-class "else if" keyword. No compound else if — the language provides orif as a dedicated construct.

signs

Declares that a class fulfills a contract. Read: "User signs Identifiable" — the class promises to implement every field and method the contract requires.

uses

Adopts a trait. Unlike contracts, traits only require methods (no fields). Complements signs for interface composition.

attach

Imports a module or specific symbols. attach io; brings in the I/O module. attach Server from websocket; imports selectively.

is

Runtime type inspection. if (value is string) { ... } checks the dynamic type without casting.

??

Null coalescing operator. result ?? "default" provides a fallback for optional values.

echo_server.an — WebSocket echo server in ~20 lines 
attach Server, WebSocket, createServer from websocket;
attach io;

let clients as list<WebSocket> = [];
let mutex as Mutex = Mutex();

func on_connect(server as Server, client as WebSocket) -> nil {
  mutex.lock();
  clients.push(client);
  mutex.unlock();
  client.send("Welcome!");
}

func on_message(server as Server, client as WebSocket,
                  message as string) -> nil {
  mutex.lock();
  for (c in clients) { c.send("echo: " + message); }
  mutex.unlock();
}

export func main() -> i64 {
  let server = createServer(8080, {
    "on_connect": on_connect,
    "on_message": on_message
  });
  while (true) { server.service(); }
}
